## 📌 About the Project

Dogs is a front-end application inspired by a social network experience.

Users can create an account, log in, publish photos, comment on posts, delete their own photos, and view profile statistics through charts.

The project was built to practice React in a more complete application structure, including routing, authentication flow, protected pages, API consumption, reusable components, and deployment.

## ✨ Features

- User account creation
- Login and logout
- Authentication with Context API
- Protected routes
- Photo upload
- Photo feed
- Individual photo pages
- Comments on photos
- Delete own photos
- User statistics with charts
- Responsive layout
- Deployment with GitHub Pages and GitHub Actions

## 🧠 Main Learnings

- React component structure
- State management with Context API
- Routing with React Router
- Protected route handling
- API integration
- Form handling
- Loading and error states
- Conditional rendering
- Data visualization with Victory Charts
- Production build with Vite
- GitHub Pages deployment using GitHub Actions
